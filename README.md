# IT5409 - Computer Vision Quiz Bank

Thư mục này chứa bộ câu hỏi ôn tập cho môn IT5409 – Thị giác máy tính (Computer Vision).

## Cách xem quiz

Mở trực tiếp file [`IT5409_study.md`](IT5409_study.md) trong repo.

File này được thiết kế để học theo dạng ẩn/hiện đáp án:

- Mỗi câu hỏi có các lựa chọn A/B/C/D.
- Phần đáp án và giải thích nằm trong phần `Hiện đáp án và giải thích`.
- Khi xem trên GitHub, bấm vào dòng đó để mở hoặc đóng đáp án.

## Nội dung

- `IT5409_study.md`: file quiz chính, bao gồm các câu hỏi, nguồn tài liệu, đáp án và giải thích.
- `course-docs/`: tài liệu môn học dùng làm nguồn tham khảo cho bài học và ôn tập.

## Môn học tương ứng

- Mã môn: IT5409
- Tên môn: Thị giác máy tính
- Nội dung tập trung vào: thu nhận ảnh, nâng cao chất lượng ảnh, phát hiện biên, trích chọn đặc trưng, phân vùng ảnh, chuyển động, theo dõi, và deep learning cho Computer Vision.
